## Rebox 0.2.4 — исправление названия внутри приложения

**Исправлено:** заголовок внутри iOS-интерфейса теперь показывает **REBOX** вместо `DOPAMINE RENEW`. Под иконкой на домашнем экране приложение также называется Rebox.

- Пересобран ARM64 iOS UI с минимальной версией **iOS 15.0**.
- В Info.plist версия приложения обновлена до **0.2.4**.
- Прежние bundle ID `org.codex.DopamineRenew`, имя исполняемого файла `DopamineRenew` и идентификатор rootless-пакета сохранены ради совместимости с установленной версией.
- Apple Developer клиент, контроллер, служба и механизмы продления остались без изменений относительно 0.2.3.

### Файлы

- `Rebox-0.2.4-rootless.deb` — iPhone с Dopamine rootless, через Sileo/Zebra; содержит LaunchDaemon.
- `Rebox-0.2.4.ipa` — для установки через TrollStore.
- `SHA256SUMS` — проверка SHA-256.

**Экспериментальный релиз.** Успешная автоматическая работа с Apple Developer не подтверждена. Ранее возникала ошибка авторизации `Apple session unavailable or expired`, её причина не установлена. Установка rootless DEB может запустить фоновую службу, выполняющую операции для выбранных приложений.

Проверены: исходный заголовок, отсутствие старой строки в собранном IPA, кодовые подписи Mach-O, `LC_BUILD_VERSION` для iOS 15.0, структура пакетов и отсутствие приватных файлов. **На iPhone в ходе подготовки релиза ничего не устанавливалось.**
